# PowerCraftStudio

Official institutional website of PowerCraftStudio, developed to present our services, products, and portfolio in English (US) and Portuguese (PT).

🔗 **Visit the site:** [https://powercraftstudio.digital](https://powercraftstudio.digital)

---

## About the Project

This repository contains the international version of the PowerCraftStudio website, serving a global audience with content available in both English (US) and Portuguese (PT).

The website features a clean, responsive design with a language selector in the top-right corner, allowing users to switch between English and Portuguese seamlessly.
